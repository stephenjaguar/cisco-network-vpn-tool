# Packet Tracer Simulation Deliverable

This folder makes the Part 1 simulation requirement explicit.

The assignment expects Cisco switch simulation with Packet Tracer or GNS3. This project targets Packet Tracer because it avoids VMware and VirtualBox, while still allowing a Cisco IOS-like switch to be configured and verified.

## Included Files

- `PACKET_TRACER_GNS3_TESTING.md`: full Part 1 simulation test guide for Packet Tracer and GNS3.
- `packet_tracer_topology.md`: topology, addressing, and Packet Tracer build steps.
- `switch_initial_setup.txt`: Cisco IOS commands to prepare the simulated switch for SSH.
- `frontend_netmiko_test_steps.md`: exact Flask frontend values for connecting to the simulated switch.

## Expected Packet Tracer File

Create the Packet Tracer lab manually and save it as:

```text
simulation/cisco_switch_vlan_lab.pkt
```

The `.pkt` file is not generated by Python; it must be created from Cisco Packet Tracer.

## Review Path

1. Build the Packet Tracer switch using `packet_tracer_topology.md`.
2. Configure SSH using `switch_initial_setup.txt`.
3. Start the Flask frontend.
4. Select `Netmiko Cisco IOS SSH`.
5. Use the values in `frontend_netmiko_test_steps.md`.
6. Verify the frontend reports `COMPLIANT`.
7. Verify the switch CLI shows the hostname and VLANs.
